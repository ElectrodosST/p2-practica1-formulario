Para la conexión, se utilizo PHP con  XAMPP para utilizar conexión SQL.
Para que funcione el inicio de sesión con la conectividad, descarga todos los archivos en una carpeta, una vez descargada en nuestros archivos de la computadora
buscamos DISCO LOCAL y dentro de ahí entramos a la carpeta XAMPP, y dentro de esa carpeta buscamos una que se llama htdocs y dentro de esa es donde pondremos nuestra carpeta creada con todos los archivos
tiene que abrir XAMPP y dale start a APACHE y MySQL y una vez encendidos los dos le da a admin en MySQL y listo
ahora para abrir el documento se abre/ejecuta de la siguiente manera

            http://localhost/proyecto/index.html

y la conexión con SQL estara lista en su inicio de sesión
